# ALPHA Command Center

เว็บแอปศูนย์สั่งการสำหรับบริษัท รปภ. สร้างเป็นโครงการใหม่แยกจากทุกระบบเดิม

## สิ่งที่ใช้งานได้ในรุ่นเริ่มต้น

- Dashboard กำลังประจำจุด: นับเป็นช่องกำลัง ไม่ใช่จำนวนข้อความหรือจำนวนคนในกลุ่ม
- สถานะ เขียว / เหลือง / แดง แยกจากป้ายมาสาย
- ผู้จัดการยืนยันเข้าเวร, บันทึกลา/หยุด, และเลือกสแปร์แทน
- Audit log สำหรับรายการสำคัญ
- งานวางบิล: ลูกค้า, ยอดเงินแบบสตางค์, วันครบกำหนด, การดำเนินการถัดไป, สถานะเอกสาร/วางบิล/รับชำระ
- ฐานข้อมูล D1 และ migration ใน source

## ขอบเขตที่ยังไม่เปิด

- LINE OA จริงและการผูกตัวตน รปภ.
- การแจ้งเตือนตาม deadline
- รายชื่อ/จุดงานจริงและการ import CSV
- เอกสารแนบ, การรับเงินบางส่วน, และ AI suggestion mode

## หลักธุรกิจสำคัญ

- จุดจะเขียวเมื่อทุกช่องกำลังของจุดนั้นยืนยันครบ
- คนมาช้าแต่ยืนยันแล้วทำให้จุดกลับเป็นเขียว พร้อมป้ายมาสาย
- สแปร์ไม่สามารถเลือกจุดเองโดยไม่มีการมอบหมาย
- ไม่มีการเช็กออกเวรในรุ่นนี้
- สถานะภายในไม่ถูกส่งไปกลุ่มลูกค้า
